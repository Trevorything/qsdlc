# qsdlc-interview

- **Stage**: [[1 - Plan]]
- **Implementation**: `/skills/qsdlc-interview/SKILL.md`
- **Triggers on**: the Plan stage of QSDLC, or generally when the user wants help nailing down a goal before implementation

## What it does

Runs a genuine back-and-forth interview — not a one-shot questionnaire — covering the problem, target users, success criteria, constraints, explicit non-goals, and prior art. Keeps going until things are actually resolved rather than writing `Intent.md` around vague answers.

## Produces

- `Intent.md` — the full written intent
- The inspiration artifact — an evocative, visual representation of the vision, not a spec

Both are shown to the user for confirmation before the stage is marked complete.
