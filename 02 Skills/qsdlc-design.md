# qsdlc-design

- **Stage**: [[2 - Design]]
- **Implementation**: `/skills/qsdlc-design/SKILL.md`
- **Triggers on**: the Design stage of QSDLC, after `Intent.md` exists

## What it does

Reads `Intent.md` and turns it into grounded requirements. For creative or novel asks, calls [[qsdlc-feature-research]] first to ground the spec in real prior art. Writes features (with acceptance criteria), system requirements, an architecture sketch, and risks.

## Produces

- `spec.md`
- The design pitch deck artifact — the AI's execution vision presented for review, using Archify for any diagrams
