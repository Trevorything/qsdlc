Pillar 01 // qsdlc-present + html-motion

Six-Stage Craft Pipeline

  • 01 Inspect & Bind (brand_probe.mjs) Extracts tokens from design standards, CSS, or Tailwind into brand-bind.json with Tier A-E confidence scoring and zero contrast misses.
  • 02 Creative Roll (roll.mjs) Rolls non-repeating combinations across 57 matrix cards (15 archetypes, 12 BI encodings, 11 motion devices, 8 finishes, 11 signatures) + live web inspiration scouting.
  • 03 Purposeful Motion (9 Engines + Kit) Inlines 2D/GPU motion engines (streams, graph, expand, pullback, split, transform, morph, shader, terrain), 8 BI chart types, and offline Diagram.layout SVG DAGs.
  • 04 Dual Gate (lint.mjs + shoot.mjs) Enforces L01-L16 offline/slop/contrast gates and Playwright multi-viewport screenshots before the artifact is marked done.
Pillar 02 // qsdlc-herdr + Official Herdr CLI

Doctored AI Agent Relay Architecture

  • Role-Isolated Tabs & Worktrees Organizes parallel Claude/Codex/Gemini workers across dedicated tabs (research, build, qa-verify) with optional isolated worktree scopes.
  • File-Staged Prompts (No Inline Escaping Bugs) Stages dense briefs in workspace scratch files and dispatches short pointer commands with --enter to prevent PowerShell quoting failures.
  • Event-Driven State Verification Probes pane state.json (idle / needs-input / done) and read-pane output directly — never wasting turns on blind sleep loops.
  • Dogfooded During This Overhaul Workspace w3 (qsdlc-overhaul) orchestrated 7 panes in parallel to research pstack/potetos, draft new factory skills, build test suites, and run QA.
